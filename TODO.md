# Looplist Marketplace

- [x] Responsive home page with prominent search, clear calls to action, category shortcuts, and a polished layout across mobile, tablet, and desktop.
- [x] Marketplace browsing with keyword search and filters for category and location.
- [x] Category navigation that lets people quickly open focused listing collections.
- [x] Reusable listing cards showing an image, title, price, seller, and location.
- [x] Featured listings and recent listings sections for curated and fresh discovery.
- [x] Listing detail view with a larger image presentation, price, description, seller information, location, and clear contact or response actions.
- [x] Favorites functionality for saving listings and reviewing saved items later.
- [x] Simple new-listing form for entering listing details, selecting a category and location, setting a price, and adding images.
- [x] Display listing prices and new-listing amounts in Indian rupees with Indian number formatting.
- [x] Chat features with seller context, conversation history, message composer, send behavior, and seller response feedback.
- [x] AI-assisted listing review flow with short-video capture guidance, condition notes, confidence, buyer-safety disclaimer, and an AI-reviewed ad badge.
- [x] Sellers can add up to four product photos or videos, with previews before publishing.
- [x] Clicking a listing opens a full detail page with swipe gestures, arrows, thumbnails, seller actions, and nearby similar-product recommendations.
- [x] Buyers can set a neighborhood or PIN-code location and use it for nearby browsing and recommendations.
- [x] Phone-number login with OTP verification flow and a customer panel for saved finds, listings, chats, profile actions, and sign out.
- [x] From-scratch UI/UX redesign applied across discovery, listing details, multi-media gallery, forms, chat, authentication, location, and customer-panel surfaces with responsive desktop/mobile behavior.
- [x] Animated design layer with hero entrance choreography, floating artwork, staggered category/listing reveals, tactile action feedback, detail-page transitions, and reduced-motion accessibility support.
